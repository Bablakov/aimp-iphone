# AIMP Web

Музыкальный плеер для iPhone в духе [AIMP](https://aimp.ru) — **сайт, который ставится на экран «Домой»**
и работает как приложение. Без сервера, без аккаунтов, без App Store: музыка лежит на самом телефоне
и играет без интернета.

> Неофициальный проект, с разработчиками AIMP не связан. Название и стиль — дань уважения любимому плееру.

Сайт: **https://bablakov.github.io/aimp-iphone/**

## Как поставить на iPhone

1. Открыть сайт в **Safari**.
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Открывать приложение **с иконки**, а не из вкладки Safari: у иконки своё хранилище, и Safari не удаляет
   его за неактивность (во вкладке данные могут пропасть через 7 дней без захода).
4. «Треки» → **+** → выбрать аудиофайлы из «Файлов», iCloud Drive или «На iPhone».
   Файлы копируются внутрь приложения, после этого исходники можно удалить.

Дальше сайт открывается и без сети; новые версии подтягиваются сами при следующем запуске.

## Возможности

- **Библиотека**: треки, альбомы, исполнители; теги и обложки читаются из файлов (ID3, MP4, FLAC и др.).
- **Плейлисты**: создание, переименование, перестановка, добавление из меню трека.
- **Очередь**: «Играть следом», «В конец очереди», переход по очереди, перемешивание, повтор (всё / один трек).
- **Эквалайзер**: 10 полос ±15 дБ, предусиление, готовые пресеты.
- **Таймер сна** (по минутам или «после этого трека») и **скорость** 0.5×–2×.
- **Экран блокировки и наушники**: обложка, название, перемотка, кнопки Play/Next/Prev (Media Session).
- **Продолжение с того места**, где остановились, после перезапуска.
- Поиск и сортировка, список держит тысячи треков (виртуальная прокрутка).
- На компьютере файлы можно просто перетащить в окно.

## Что важно знать

- **Форматы** — те, что умеет Safari: MP3, M4A/AAC, WAV, AIFF, FLAC. **OGG, WMA, APE iOS не играет** —
  такие файлы при импорте пропускаются, и приложение об этом скажет.
- **Место.** Сколько музыки влезет, решает iOS; занятое место видно в «Ещё». Без иконки на «Домой»
  Safari лимитирует хранилище строже.
- **Эквалайзер** включается вручную: пока он выключен, звук идёт напрямую через `<audio>` — это самый
  надёжный путь для фонового воспроизведения. Включённый эквалайзер пропускает звук через Web Audio; если
  на вашей версии iOS при этом пропадает звук с выключенным экраном — выключите его и перезапустите приложение.
- **Без пауз между треками (gapless) нет**, и звук не затухает при таймере сна: iOS не даёт веб-страницам
  менять громкость.
- Если удалить иконку с экрана «Домой», удалится и её хранилище вместе с музыкой.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173/aimp-iphone/
npm test           # тесты логики очереди
npm run build      # проверка типов + сборка в dist/
npm run icons      # перерисовать иконки из scripts/make-icons.mjs
```

Стек: Vite, TypeScript, Preact + signals, IndexedDB (`idb`), `music-metadata`, Workbox (`vite-plugin-pwa`).

```
src/core/   очередь, плеер (один <audio>), библиотека и импорт, эквалайзер, хранилище
src/ui/     экраны и компоненты
```

Деплой — GitHub Actions (`.github/workflows/pages.yml`): тесты → сборка → GitHub Pages на каждый push в `main`.
Базовый путь `/aimp-iphone/` задан в `vite.config.ts` — при переименовании репозитория поменять его там и в `index.html`.
